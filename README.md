| 项目 | 描述 | 状态 |
|------|------|------|
| 01-SpaceShooter | 太空射击，练习游戏循环与碰撞 | 🚧 进行中 |

## 🛠️ 构建说明

```bash
# 克隆
git clone https://github.com/你的用户名/sfml-summer-2026.git
cd sfml-summer-2026

# 构建（需要 CMake + SFML）
cmake -B build
cmake --build build --config Release
